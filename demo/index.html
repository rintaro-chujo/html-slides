通知はいつ届けば、行動につながるのか？

問いを大きな一言で立てる。見出しは付けない。

提案：行動の記録から通知時刻を決める

  • 習慣は決まった文脈の中で形成されやすい Example & Sample, 2020
  • 過去2週間の起動時刻から、その人が開きやすい時間帯を推定
  • 推定した時間帯の直前に通知し、反応がなければ翌日にずらす

文献は使った箇所の直後に .cap で灰色小字。下部にまとめない。図は inline SVG で描く。

結果（架空）：個人化した時刻で継続日数が伸びる

数値はすべて架空。平均±SE。brackets で検定結果、group で2本をまとめた計画対比

data-chart の JSON から SVG の棒グラフを描く。groups に label・mean・se・color、軸は ymin・ymax・step・ticks、fmt:"pct" で百分率。

メカニズム（架空）：「ちょうどいい」感覚を介して効く

実線＝有意な経路、破線＝直接効果（非有意）。係数と注記は SVG の text で書く

媒介モデルやパイプラインは inline SVG で描く。色は黒・赤・灰だけ。
