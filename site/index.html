html-slides ビューア

HTML で書いたスライドの発表フォルダ（index.html と assets/）を開いて、発表・編集・PDF 化します。 ファイルはこのブラウザの中だけで読み書きし、どこにも送りません。

開いているフォルダ

    スライドは新しいタブで開きます。このタブを閉じると表示できなくなるので、発表中も開いたままにしてください。 PDF は印刷画面で「PDF に保存」を選び、余白「なし」・背景のグラフィック「オン」にします。

    最近のフォルダ

      スライドの作り方

      1枚が <section class="slide">（1920×1080）。雛形の deck.css と deck.js を読み込むだけで、 本番表示・発表者ビュー（ノート・タイマー・次スライド）・タブ間の同期・印刷用表示が使えます。

      <link rel="stylesheet" href="https://rintaro-chujo.github.io/html-slides/v1/deck/deck.css">
<div id="deck">
  <section class="slide"><h2>見出し</h2><div class="body"><p>本文</p></div>
    <aside class="notes"><p>発表者ノート</p></aside></section>
</div>
<script src="https://rintaro-chujo.github.io/html-slides/v1/deck/deck.js"></script>

      雛形 index.template.html ・ 部品の例 snippets.html ・ 見本のスライド（発表者ビュー） ・ GitHub

      キー：→ / Space 次、← 前、F 全画面、S 発表者ビュー、O 一覧、数字+Enter ジャンプ、? ヘルプ。 v1 は 1.x の最新版を指します。見た目を固定したいときは v1.1.0 のように版まで書きます。 PNG・PowerPoint への書き出しと、オフラインでの発表は、リポジトリの tools/serve.py・tools/export.py を使ってください。
